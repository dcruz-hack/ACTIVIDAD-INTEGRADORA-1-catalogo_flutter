# Catálogo - ZM TECHNOLOGY

## Descripción

Aplicación móvil desarrollada con Flutter para mostrar un catálogo de productos tecnológicos. 
Permite consultar información detallada de cada producto y navegar entre diferentes pantallas.

## Objetivo

Desarrollar una aplicación con una estructura modular, componentes reutilizables, navegación entre pantallas y transferencia de parámetros.

## Tecnologías utilizadas

* Flutter
* Dart
* Git
* GitHub
* Visual Studio Code

## Estructura del proyecto

text
lib/
├── main.dart

│   └── detail_screen.dart
├── widgets/

└── models/
    └── product.dart


## Funcionalidades

* Catálogo de productos tecnológicos.
* Visualización de precios y descripciones.
* Tarjetas de productos reutilizables.
* Navegación mediante Navigator.push y Navigator.pop.
* Transferencia de parámetros entre pantallas.
* Formulario para solicitar información.

## Instalación y ejecución

1. Instalar Flutter y Dart.
2. Clonar el repositorio.
3. Abrir una terminal en la carpeta del proyecto.
4. Ejecutar `flutter pub get`.
5. Ejecutar `flutter run`.
